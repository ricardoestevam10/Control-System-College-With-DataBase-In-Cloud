# Controle de Notebooks — Front-end

React + TypeScript + Vite, integrado ao back-end Express.

## Como rodar
1. Suba o back-end (`npm start` na pasta back-end, porta 8080).
2. Aqui: `npm install` e `npm run dev`.
3. Abra o endereço mostrado no terminal (normalmente http://localhost:5173).

A URL da API fica em `.env` (`VITE_API_URL`, padrão `http://localhost:8080`).
